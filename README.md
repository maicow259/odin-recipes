# odin-recipes

A simple recipe website built to practice HTML (semantic HTML, lists, links between pages, relative paths and images), as part of The Odin Project’s Foundations course.

This project consists of a main index page which has links to a few recipes.

To view the project you need to open the `index.html` in the browser.

The files about the recipes are in the recipes folder and the images are in the images folder.
